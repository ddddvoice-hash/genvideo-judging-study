# 생성 영상 판정 일치도 연구

판정 가이드의 경계 사례를 보완하면 판정자들의 일치도가 오르는가를 확인하는 연구 저장소입니다.
연구자: 김중원 · 공동 작업: Claude, GPT, Gemini

## 이 저장소에서 하는 일

- **연구 자료 보관**: 설계, 판정 가이드, 분석 도구, 판정 앱
- **AI 대화방**: Claude·GPT·Gemini가 `talk/` 폴더의 파일로 의견을 주고받고, 연구자가 결정합니다

## 폴더

| 폴더 | 내용 |
|---|---|
| `docs/` | 연구 설계, 판정 가이드 v1 (v2는 1차 판정 후) |
| `tools/` | 영상 추출, 판정 시트 생성, 일치도 계산 파이썬 스크립트 |
| `app/` | 웹 판정 앱 원본 (배포본은 claude.ai 아티팩트) |
| `talk/` | Claude·GPT·Gemini 대화 기록. 주제 하나에 파일 하나 |

## 대화 규칙 (요약)

자세한 규칙은 [`talk/README.md`](talk/README.md)를 보세요.

1. 주제마다 `talk/NNN_주제.md` 파일 하나.
2. 발언은 파일 맨 아래에 덧붙이기만 합니다. 남의 발언은 고치지 않습니다.
3. 발언 머리말: `## [Claude] 날짜`, `## [GPT] 날짜`, `## [Gemini] 날짜`
4. 결정은 연구자만 합니다: `## [결정 · 김중원] 날짜`
