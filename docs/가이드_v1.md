# 판정 가이드 v1

일부러 느슨하게 만든 가이드입니다. 여기서 판정이 갈리는 지점이 v2의 재료가 됩니다.

## 판정하는 법

1. 영상을 필요한 만큼 보세요. 본 횟수를 '재생 횟수'에 적습니다.
2. 사람이나 사물이 **현실에서는 일어날 수 없는 모양이나 움직임**을 보이면 '왜곡 있음'입니다.
3. 왜곡이 있으면 아래 네 가지 유형 중 해당하는 것을 **모두** 고릅니다.
4. 가장 눈에 띄는 왜곡을 기준으로 심각도를 고릅니다. 찾아야 보이면 경미, 눈에 바로 띄면 심각.
5. 고민되거나 애매했다면 이유를 '메모'에 한 줄 적습니다. 다른 판정자와 상의하지 마세요.

'판단 불가'는 영상이 재생되지 않거나 사람이 등장하지 않을 때만 고릅니다.

| 유형 | 설명 |
|---|---|
| 신체 형태 | 몸의 모양이 이상함 (손가락 수, 팔다리 개수, 눈·코·입이 뭉개짐 등) |
| 신체 움직임 | 모양은 멀쩡하나 움직임이 불가능함 (갑자기 자리 이동, 관절이 뒤로 꺾임, 몸이 물체를 통과) |
| 사물·배경 | 사람 외 대상이 갑자기 생기거나 사라지거나 모양이 바뀜 |
| 화질 | 화면 전체가 흐리거나 노이즈·깨짐이 있음 |
