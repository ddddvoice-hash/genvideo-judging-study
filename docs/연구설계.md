# 연구 설계

**가제:** 판정 가이드의 경계 사례 보완이 생성 영상 왜곡 라벨의 판정자 간 일치도에 미치는 영향

## 연구 질문

1. **RQ1.** 간단한 가이드(v1)로 판정하면 판정자들은 얼마나 일치하고, 어디서 갈리는가?
2. **RQ2.** 갈린 사례를 유형화해 보완한 가이드(v2)는 일치도를 높이는가?
3. **RQ3 (보조).** 사람의 왜곡 판정은 데이터셋에 이미 있는 화질 점수와 얼마나 관련 있는가?

## 데이터

| 후보 | 라이선스 | 결정 |
|---|---|---|
| VideoFeedback (TIGER-Lab, VideoScore) | Apache-2.0 | 채택: 생성 모델 11종, 약 3.7만 개, 5개 항목 1~4점 사람 점수 |
| VBench sampled video | MIT | 보조 (731GB, 다운로드 전 연락처 제공 동의) |
| T2VQA-DB | 표기 없음 | 제외 |

- 프롬프트에 사람이 등장하는 영상만 고름 (`tools/01_sample_videos.py`의 단어 목록)
- 화질 점수 1~4점 층마다 60개 → 240개, 층별로 반씩 세트 A·B (각 120개)
- 논문에는 영상 ID와 캡처만 싣고 영상은 재배포하지 않음

## 판정 항목

왜곡 유무(없음/있음/판단 불가) · 유형 다중선택(신체 형태/신체 움직임/사물·배경/화질) · 심각도(경미/심각) · 재생 횟수 · 메모

## 분석

| 무엇을 | 어떻게 | 질문 |
|---|---|---|
| 항목별 일치도 | Fleiss 카파, 영상 단위 부트스트랩 2,000회 95% 구간 | RQ1 |
| 갈린 영상 | 4명 중 2:2 또는 3:1 + 메모 → 유형화 | RQ1 → v2 |
| v1 대 v2 | 세트 A(v1) 대 세트 B(v2), 세트 A(v1) 대 세트 A(v2) | RQ2 |
| 화질 점수와의 관계 | 스피어만 상관 | RQ3 |
| AI 판정자 (보조) | 장면 캡처로 Claude 판정, 사람 다수결과 Cohen 카파 | 보조 |
